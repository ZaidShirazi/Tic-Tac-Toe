# Tic-Tac-Toe Game

A clean, responsive, and interactive **Tic-Tac-Toe web game** built using modern web development practices. 

## 🛠️ Tech Stack
* **HTML5:** Semantic markup structure.
* **CSS3:** Custom styles featuring responsive fluid design, Flexbox layouts, and dynamic media queries.
* **JavaScript (ES6):** Game logic handles win conditions, draw checks, and state management.
